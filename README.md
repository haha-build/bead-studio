# BEAD STUDIO · 串珠工作室

可直接部署到 GitHub Pages 的静态网站，无需安装依赖或构建。

## 文件

- `index.html`：完整网站，已内嵌工作板、场景和透明珠子素材。
- `.nojekyll`：使 GitHub Pages 直接提供静态文件。

## 发布

1. 在 GitHub 新建一个仓库。
2. 将本文件夹内的文件上传到仓库根目录，确保根目录直接有 `index.html`，不要再套一层文件夹。
3. 在仓库 Settings → Pages 中，选择从分支部署（Deploy from a branch）。
4. 选择 main 分支与根目录（/ root），保存。
5. 部署完成后，从 Pages 页面打开网站链接。

## 当前功能

珠子增删、紧密排列与满圈闭合、撤销重做、手链／项链切换、长度统计、素材库、图片上传、背景更换、图片导出、浏览器自动保存。

## 使用说明

- 双击 `index.html` 可在本机使用。
- 作品和上传图片保存在当前浏览器，不跨设备同步。
- 从本地文件改用 GitHub Pages 后，网址发生变化，浏览器不会自动迁移原来的作品数据。
- 上传图片后会在浏览器本地自动去底，显示透明棋盘格预览；可调整强度、点选底色、拆分分开的珠子，确认后保存为透明素材。纯色底图效果较好；复杂背景、透明玻璃或与背景同色的珠子可能需要调整。上传入口也可重新处理已有素材。
- 珠子尺寸用于模拟，不能替代实物测量。

## 素材

工作板、场景背景和珠子来自用户提供的图片；珠子去底使用 imagegen 编辑。原始参考图分辨率较低，透明素材的细节可能与原图略有差异。

本文件夹只包含发布需要的文件，不包含聊天记录、登录凭据或本浏览器保存的作品。



## 成品作品集
右上角保存成品可命名保存当前作品。从菜单「我的成品」可查看、继续编辑和导出 PNG。成品保存在当前浏览器的 IndexedDB 中，不跨设备同步；清除网站数据会移除成品，建议导出图片备份。
